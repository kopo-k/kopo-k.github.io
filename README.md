# kopo-k.github.io

ゲームエフェクトアーティストを目指すポートフォリオサイト。

**https://kopo-k.github.io/**

## 構成

`index.html` 1枚。ビルド不要、依存ライブラリなし、**画像0枚**。
背景の夕暮れの風景は、CSSとインラインSVGだけで描いています。

`tools_gen_sky.py` は、その背景SVG（空の帯・光条・雲・稜線・水面の映り込み・電柱・鳥・草）を
生成して `index.html` に差し込むスクリプトです。構図を変えたいときはこれを編集して実行します。

```bash
python3 tools_gen_sky.py
```

## デザイン方針

セルルック（アニメ調）をWebで再現しています。使っているのは3つだけです。

- 太い輪郭線（`border: 3px solid`）
- 段階を持つ塗り（グラデーションの停止位置を重ねる）
- ずらした影（`box-shadow` のぼかし半径を 0 にする）

**ぼかしを一切使わない**のが決め手で、通常のドロップシャドウを1つ混ぜるだけで写実寄りに戻ります。

## 更新のしかた

`index.html` を編集して push すると、数十秒で反映されます。

```bash
git add -A && git commit -m "更新" && git push
```

## 編集が必要な箇所

- CONTACT セクションの連絡先（赤い破線の部分がプレースホルダ）
- WORKS の作品（CG作品ができたら差し替える）
